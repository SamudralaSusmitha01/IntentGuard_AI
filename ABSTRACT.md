The rapid growth of digital technologies has significantly improved access to information and communication; however, it has also increased digital distractions that negatively affect productivity, concentration, and task completion. Existing productivity applications primarily rely on rule-based website blocking, timer-based reminders, or manual task tracking, which fail to understand the user's actual intention or the context of ongoing activities. To overcome these limitations, this project proposes CogniGuard AI, an intelligent context-aware productivity assistant that leverages Multimodal Large Language Models (LLMs) and Agentic AI to monitor user activities, identify distractions, and provide personalized interventions in real time.
The proposed system begins by capturing the user's task intention through an interactive interface and refines it using an AI-driven intention understanding module. During task execution, the application continuously analyzes screenshots, extracted on-screen text using Optical Character Recognition (OCR), active application metadata, browser URLs, and system events to build a comprehensive understanding of the user's current context. A multimodal reasoning engine semantically compares the user's ongoing activity with the declared intention to determine whether the user is focused or distracted. Based on this analysis, an autonomous decision-making agent generates adaptive, context-aware, and non-intrusive notifications that help users regain focus while minimizing workflow interruptions. The system also maintains a personalized memory of user preferences, work patterns, distraction history, and feedback to continuously improve intervention strategies and focus prediction accuracy over time.
A key feature of the proposed solution is its ability to operate seamlessly in both online and offline environments. When an internet connection is available, the application utilizes cloud-based multimodal AI models to perform advanced contextual reasoning, personalized recommendations, and intelligent conversational assistance. During offline operation, the system automatically switches to lightweight on-device AI models and locally stored user data to continue monitoring screen activities, detecting distractions, generating productivity insights, and maintaining uninterrupted functionality without compromising user experience. This hybrid architecture ensures high availability, reduced latency, enhanced privacy, and reliable performance regardless of network connectivity.
The system is implemented using Python, FastAPI, React.js, Google Gemini/OpenAI Multimodal LLMs, EasyOCR/Tesseract OCR, PyAutoGUI for screen capture, SQLite/PostgreSQL for secure data management, ONNX Runtime or Ollama for local offline inference, and Docker for containerized deployment. By integrating multimodal intelligence, context-aware reasoning, agentic decision-making, adaptive personalization, and hybrid online–offline AI processing, the proposed system provides an accurate, scalable, and privacy-aware productivity assistant that promotes intentional computing, reduces digital distractions, enhances user focus, and supports sustainable productivity for students, researchers, and working professionals.
