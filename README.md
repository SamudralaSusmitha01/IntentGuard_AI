# 🛡️ IntentGuard AI

> An AI-powered context-aware productivity assistant that uses Multimodal LLMs and Agentic AI to understand user intent, detect digital distractions, and provide personalized real-time interventions.

## 📌 Overview

The rapid growth of digital technologies has improved access to information and communication, but it has also increased digital distractions that can negatively affect productivity, concentration, and task completion.

**IntentGuard AI** is an intelligent productivity assistant designed to understand what the user intends to accomplish and compare that intention with their ongoing digital activity.

Unlike traditional productivity applications that mainly depend on website blocking, timers, or manual task tracking, IntentGuard AI uses **Multimodal Large Language Models (LLMs)** and **Agentic AI** to understand the user's context and provide adaptive interventions.

## 🎯 Objectives

- Understand and refine the user's intended task using AI.
- Monitor the user's digital activity in real time.
- Analyze screenshots and on-screen text using OCR.
- Track active applications and browser activity.
- Detect whether the user's current activity is focused or distracting.
- Provide personalized and context-aware interventions.
- Learn from user preferences, work patterns, distraction history, and feedback.
- Support both online and offline operation.
- Improve productivity while minimizing unnecessary interruptions.
